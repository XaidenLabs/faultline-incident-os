# Agent Trajectories

## Required artifacts

- `artifacts/trajectories/featured-replay.jsonl`: credential-free representative replay.
- `artifacts/trajectories/challenge-counterfactual.jsonl`: the hard case, including the rejected checkout experiment and successful network experiment.
- `artifacts/trajectories/inc-2481-live.jsonl`: generated by a live model run.

## Reading a trajectory

Each line is one append-only JSON event. Relevant fields include:

- `sequence`: stable event order;
- `at`: UTC timestamp;
- `actor` or `type`: investigator, verifier, tool, model input or model output;
- `action`: selected reasoning or tool step;
- `arguments`: exact tool arguments;
- `output`: exact bounded tool response;
- `usage`: provider-reported token usage when available.

## Agent instructions

The complete instructions are versioned in `core/prompts.mjs`. They require competing hypotheses, evidence citations, isolated counterfactuals, allowed actions, human approval and explicit uncertainty.

## Human checkpoints

Diagnostic counterfactuals run automatically because they touch only fresh synthetic snapshots. The consequential recovery remains a proposal requiring human approval. Production execution is not implemented.
